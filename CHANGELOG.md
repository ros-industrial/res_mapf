# Changelog

All notable changes to the `res_mapf` Python packages are documented here.

## 0.1.0

Initial GitHub Release of the lockstep Python packages:

- `res_mapf` — meta package depending on the four members below
- `res_mapf_planning` — MAPF solving and plan generation
- `res_plan_execution` — plan execution and robot controllers
- `res_plan_server` — plan server coordinating agents
- `res_pybullet` — PyBullet simulation environment

Wheels and sdists are published as GitHub Release assets (not on PyPI).
ROS packages (`res_ros2`, `res_ros2_msgs`) are not included in this release.
